        ⇨ Volmeter : computing electric energy<br>
        ⇨ Speedometer : computing speed(car,bike)<br>

          ⇨ Digital data can be : <br>
             Text<br>
             Numbers<br>
             Audio<br>
             Videos<br>
             Images<br>
             ↳ These all are converted into binary. 
     3. <u>Hydrid computer</u><br>
